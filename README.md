# 🚀 n8n Survey Form & Customer Feedback Automation

An advanced, production-ready workflow built in **n8n (Self-Hosted on VPS / Docker)** to seamlessly capture form submissions, intelligently route user feedback based on satisfaction levels, and trigger real-time management alerts.

---

## 🏗️ Architecture & Tech Stack

- **Automation Engine:** n8n (Community Edition, Self-Hosted via Docker on ParsPack Cloud VPS)
- **Environment:** Ubuntu (WSL 2 / Linux VPS), Nginx, Certbot (SSL via sslip.io)
- **Data Storage:** Google Sheets API (Multi-sheet conditional appending)
- **Notifications:** Gmail API (Automated targeted management escalation)
- **Version Control:** Git & GitHub
